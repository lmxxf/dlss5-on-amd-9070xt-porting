## 1. Round 2 核心突破与候选实测结论

1. **两组 `2×2` 破坏性敏感度探针（`probes-2x2-statistics.json`）**：
   - **C32 家族**（`P0` = 旁路 Box-Muller 噪声生成，`P1` = 旁路 Softmax 指数映射、`ones` WMMA 分母与倒数缩放，`P2` = 两者同时旁路）：
     - `Base - P0` 在 `original1088 / small1080 / small900` 上仅为 **`+16.89 / +21.29 / +13.86 µs`**，证伪了 Round 1 报告中“Prefix 慢 180 µs 主要来自内联 Box-Muller 噪声”的未验证假说；
     - `Base - P1` 高达 **`+664.42 / +448.60 / +347.40 µs`**，交互项仅 `-7.35 / -6.09 / +3.18 µs`，确立 C32 Softmax 辅助算术与分母归约为第一优先级靶点。
   - **ViT QKV 家族**（`P0` = 旁路 W5 权重 LDS 转发与 6 次 barrier，`P1` = 旁路尾部 Q/K 归约与缩放，`P2` = 两者同时旁路）：
     - `Base - P0` 为 **`+33.09 / +29.51 / +27.95 µs`**，`Base - P1` 为 `-2.03 / +7.56 / +7.91 µs`。
2. **分支 R2-D（C32 全系与 C64/C128/C256/SP 全系 Softmax `ones` WMMA 分母倒数 `8 -> 1` 外提，Promoted ✅）**：
   - **物理机制**：在 `hip/wave_owned_c32.inc:467` 与 `hip/wave_owned_mh.inc:689` 的 `__builtin_amdgcn_wmma_f32_16x16x16_f16_w32_gfx12(ones, ex, sums)` 中，第一操作数 `srcA` 为 `ones`（全 `1.0` 矩阵），因此同一列（同一 lane）的 8 个累加器元素满足 `sums[0] == sums[1] == ... == sums[7]`（已在 `Development/results/c512-den-typed-basis-20261006/README.md` 硬件实证）。将其外提为标量 `const float inv = norm_inverse(sums[0]);` 与 `const float inv = w2_inverse(sums[0][0] + sums[1][0]);` 后：
     - `c32-wave1*` 全系 19 个 `_w16` 核每个静态指令净减 `-10` 条，Softmax `v_rcp_f32` 从 `8 -> 1`（核总 `v_rcp_f32` 从 `9 -> 2`）；
     - `c64-wave2*` 全系 26 个 `c64/c128/c256_wave2` 核每个静态指令净减 `-13 ~ -15` 条，Softmax `v_rcp_f32` 从 `8 -> 1`（核总 `v_rcp_f32` 从 `9 -> 2`）；
     - `swin-persistent*` 全系 `sp_run64/128/256(_w16)` 与 `sp_recover64/128/256(_w16)` 8 个核每个静态指令净减 `-5 ~ -52` 条，核总 `v_rcp_f32` 从 `8 -> 1`。
   - **实测结果**：
     - `r2d_c32`、`r2d_mh`、`r2d_both` 各自七档 42 帧 Gold 全部 `0 bit-diff`（`invalid=0`）；
     - 100MHz 硬件实时钟探针（对比 `e7b234e7`）：`r2d_c32` 在 `Orig1088 / Small1080` 上 C32 阶段净快 **`-14.41 µs (3/3) / -4.45 µs (3/3)`**，全网 `-20.12 µs (3/3) / -1.63 µs`；`r2d_mh` 在 `Orig1088 / Small1080` 上 C64+C128 净快 `-2.64 µs (3/3) / -3.75 µs (3/3)`、`sp_run256` 净快 `-7.74 µs`，全网 `-12.35 µs (3/3) / -5.89 µs (2/3)`；**组合 `r2d_both` 在 `Orig1088 / Small1080` 上全网实时钟净快 `-25.21 µs (3/3) / -16.14 µs (3/3)`**（其中 C32 `-9.32 / -10.29 µs`，C64+C128 `-12.20 / -5.53 µs`）！
     - 四档 3 轮 Frame ABBA（`r2d_both` 对比 `e7b234e7`）：`original1088` **`-22.802 µs`（p99 `-17.083 µs`，3/3 轮）**、`original960` **`-22.904 µs`（p99 `-51.789 µs`，3/3 轮）**、`small900` **`-7.459 µs`（p99 `-34.474 µs`，3/3 轮）**、`small1080` `+0.129 µs`（p99 `-5.326 µs`，2/3 轮赢）。
3. **分支 R2-A（`vit_stream_qkv_frag_bin_w5f8_*` 局部改写，`r2a1` / `r2a2`）｜STOP**：
   - `r2a1`（Q/K 平方和归约循环 `unroll 8`）与 `r2a2`（W5 权重指针预计算外提）七档 Gold `0 bit-diff`，但 100MHz 硬件实时钟 `vit_qkv` 在 `Orig1088 / Small1080` 上分别退步 `+4.45 / +0.70 µs`（`r2a1`）与 `+12.21 / +3.43 µs`（`r2a2`），判定 STOP。
4. **分支 R2-B（`c128_wave2_bi_bo/ho` 压入 `<= 240 VGPR`，`r2b`）｜STOP（查明 LDS 驻留天花板）**：
   - 在 `c128_wave2` 的 `ht` 循环头重算 `ffn_tid` 并对 `upw` 指针做 SGPR `readfirstlane` 标量化后，成功将 `c128_wave2` 全系 9 个核从 `242 VGPR` 压入 `236~240 VGPR`（`c128_wave2_bi_bo/ho = 240 VGPR`，跨入 6 waves/SIMD 寄存器桶，`0 spill`），七档 Gold `0 bit-diff`。
   - 100MHz 硬件实时钟实测 `c128_wave2` 为 `+0.637 µs`（`Orig1088`，0/3 轮）与 `+0.987 µs`（`Small1080`，0/3 轮），判定 STOP。
   - **根因查明（回应闇 P2 第 6 条质询）**：`c128_wave2` 每 WG 含 4 waves 并固定占用 **16 KiB LDS**；在 `gfx1201`（WGP 模式 128 KiB LDS / 8 SIMD，或 CU 模式 64 KiB LDS / 4 SIMD）上，**LDS 硬上限本身就把最大驻留锁死在 8 WGs/WGP（4 WGs/CU）= 4 waves/SIMD**！因此将 VGPR 从 242（5 waves/SIMD）压到 240（6 waves/SIMD）后，实际有效驻留 `min(VGPR_waves, LDS_waves)` 仍为 `min(6, 4) == min(5, 4) == 4 waves/SIMD`，驻留零提升而每轮 `ht` 多执行了坐标重算 ALU。
5. **`small1080` 上 K5 隔离复核（`k5_iso_s1080`，回应闇 P1 第 2 条）**：
   - 在固定启用 `r2d_both` 的最终代码上，对 `small1080` 单独运行 `K5 off` vs `K5 on` 的 3 轮 4-slot Frame ABBA：
   - 结果：**`K5 on` 3/3 轮全胜，mean `5.375699 -> 5.359803 ms`（净快 `-15.896 µs / -0.30%`），p99 `5.579243 -> 5.552264 ms`（净快 `-26.979 µs`），分轮 `-31.893 / -9.099 / -6.697 µs`**，证明 K5 在 `small1080` 上具有真实稳定的正收益，正式保留。
