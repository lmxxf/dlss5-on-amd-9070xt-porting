Reference concepts: SAOG0721/Magpie `2fceab5e241bc9f8ded001ab3266762f1f8bc51e`, residual multiplier / low-high gain / local compression. Independently implemented in the existing codec encoded domain, with no copied GPL shader expressions, SDR/Oklab conversion, or extra NN invocation. This does not claim equivalence to a second NN or improved objective/reference accuracy.

For x=original, y=current NN, r=y−x, guided low reconstruction and low-only history are reused from mode2. Current high=r−low remains current. MODE3 adds `s*(.5*stableLow+high)` to `y+(stableLow−low)`. Strength defaults1 (0..2). Weak non-clipped correction gains at1 are low1.5 / high2, including cold/reset frames. Zero strength skips the entire output write even with valid history, preserving y bit-for-bit. A maximum-channel soft-knee limits only the extra increment, not the already-computed NN correction. Uniform headroom scaling keeps the entire new RGB change direction; already-out-of-codec-range y is untouched. No current residual / failed black output bypasses enhancement and old history.

Unknown motion remains explicitly static; known valid unjittered motion uses existing admission. History/reset/resource retirement follow mode2. Existing modes0/1/2 and runtime ABI layouts are unchanged; mode2 Update else retains its old expression. Defaults remain MODE0. No player config/DLL/module/package was written.
