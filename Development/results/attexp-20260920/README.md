## 没有收益、负收益或被替代的方案

| 实验 | 实测发现 | 决策 |
|---|---|---|
| 选择性attention的早期动态分支、额外head-major/转置布局 | 分支版最高慢约0.5ms；布局预处理成本抵消大部分合并收益 | 不采用；保留其过程中发现的无损流式改写 |
| 错误逻辑网格“空间相邻” | 忽略Gather的16-token重排，不能称真实空间邻接 | 纠正为raster坐标配对，旧结果降格解释 |
| 原图变化检测提前同stream／aux并行 | 同stream约+0.007/+0.024ms；aux约+0.426/+0.427ms；72对输出一致 | 都不采用；HIP event诊断出现负/近零时间，不拿它解释根因 |
| 简单历史线性外推 | CPU特征误差平移17.56%→22.68%，曝光15.44%→19.95% | 比hold更差，不采用 |
| INT4逐行、分组、旋转、平衡、clip、低秩筛选 | 全部GPU原型尚未胜FP8；CPU/单层特征误差逐行约32.6%，平衡旋转分组13.6%，rank32约12.6% | 精度能改善，速度未过关；低秩只做CPU筛选，未做GPU速度测试 |
| INT4 tile N16/N32/N128；分段/Graph诊断 | 未拿到稳定优势；一次Graph快14.7%未复现；不能拼接跨轮最快数字 | 不采用；Graph也不是当前R3游戏管线模式 |
| C32稀疏展开32→128（融合核内） | 动态分支整网+0.167ms；专门编译13.2515→13.2494ms，仅约−0.002ms；RGB MAE1.708/255 | 无可确认提速，不部署 |
| C32稀疏收缩128→32，展开原版 | LDS转置13.2496→13.2695ms；寄存器转置13.2479→13.5622ms；两版输出同，RGB MAE1.085/255 | LDS无收益、寄存器负优化；都不部署 |

证据：[调度](../vit-image-overlap-20260920/report.md)、[INT4总报告](../int4-ffn-20260920/report.md)、[tile两端](../int4-ffn-20260920/tile-sweep/report.md)、[C32展开](../c32-sparse-20260920/report.md)、[C32收缩](../c32-contract-sparse-20260920/report.md)。C32收缩改变了残差加法顺序，和同剪枝普通FP8仅有很小输出差异；不是逐位等价的原网络。
