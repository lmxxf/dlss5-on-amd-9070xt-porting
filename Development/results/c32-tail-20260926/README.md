# C32 单 wave 核 finish/prefix 尾部（2026-09-26）：null，不采用

基线：当前生产（0.31 + C32 vec-input，c32-wave1 gfx1201 `7AC34418…`）。尾部 = finish/finish_dcrop/prefix 核里 LDS 残差 → main（f32，prefix 为 FP8 字节）写出 + 2×2 下采样 down 写出，占各自核周期 21～26%（`results/c32-wave-phase-20260926`）。

## 定性（读 ISA）

- 旧写法两遍：main 按 64 个像素逐个 `ds_load_u16` + F() + 写；down 16 个 2×2 块又把同样的值读一遍（共 128 次 LDS 读），每次写出都算 64 位地址（`v_lshlrev_b64` + 进位加）。
- lane = 通道：每次写出 32 个 lane 正好是一个像素连续的 128B（prefix main8 为 32B），跨 lane 合并已最理想。尾部主体是写出量：每窗口 main 8KB、down 2KB，这是下游消费的格式，逐位约束下不能减。
- 与 §7 已否定的"C32 转置尾部并宽"不同：那次改的是 lane↔行映射（转置后残差/缩放读变差）；本次不动映射，只合并两遍遍历、去掉重复 LDS 读和 64 位地址。

## 候选

`CW_TAIL_QUAD=1`（`hip/wave_owned_c32.inc`，默认 0）：按 16 个 2×2 块遍历一次，4 次 LDS 读同时供 main 与 down；写地址用 32 位字节偏移。逐元素算术与顺序不变。ISA：finish 2333→1777 行，64 位地址移位 18→0，零 scratch。

实验 `Development/HIP/experiments/c32-tail`：整模块替换 c32-wave1；cand1 = 与生产同源同宏的对照（量噪声），cand2 = +CW_TAIL_QUAD。两档各 3 组 200 帧 ABBA，每槽首尾 RGB 逐位；每候选 16 帧动态历史，全部 bitdiff=0（两档共 64 帧）。

收益落在同源对照的噪声带（−0.013～+0.024ms）内，**不采用**，宏保持默认 0，生产配方不变，无部署包。

## 结论

尾部是写出带宽形状的开销，合并访问已最优；LDS 重复读与地址运算不在关键路径上。C32 余下可动的大段只剩 FFN（~38%，矩阵 + 激活/FP8 打包 VALU 串行链，与 ViT attention 同类）与特征打包 + QKV（~12%）。
