# Temporal consumer F9 persistence guard

Observed runtime diagnosis was supplied by the game log audit: Sword had requested MODE3 but MP2 in custom/native config, failed temporal MP1 admission, and subsequently processed no NR frames. Correct loader/desired MODE3 did not prove any enhancement dispatch. The F9 source explained how this invalid persisted setting could be created: NativeHipNetwork polled the hotkey and CycleMultiPass wrote both configuration layers before RequireSinglePass rejected the new snapshot.

The fix passes actual consumer eligibility to PollMultiPassHotkey. A key edge is still consumed; active temporal consumers1/2/3 return before CycleMultiPass rewrites config or sets force_reload. Mode0 retains the old allowed cycle. Manual invalid MP values still fail closed at the existing startup/hot snapshot checks. The error now names all modes1/2/3. The candidate does not change shaders, residual mathematics, decoder timing or the standalone Runtime ABI.

CPU fixture uses only its own executable-side DLSS5-AMD directory: three blocked cycles leave default/custom/native bytes unchanged, default allowed cycle still writes both layers, an existing unsupported value remains untouched, and manual invalid MP2 is rejected with the updated message. First PowerShell wrapper treated the normal allowed-cycle stderr notice as an exception (42442); corrected asynchronous standard-stream redirection passed, without production source change. Official O2 addon59277 exit0, SHA256 `ea11c8a602e66277a5a3d57ce8cdfa5ce730903368bd950ef2d6c421d224aca2`. No GPU, game-config write, or candidate deployment was performed by this test.

Read-only output/cache audit of e8fa source: Frame output filtering writes the same shared network RGB buffer consumed by NativeRgbTexture and by the direct io_fuse decoder path. NativeRgbTexture copies this buffer; it does not rerun/overwrite NN output. MODE3 Pad branch is outside the Past condition, so cold spatial enhancement is not dependent on history. NativeCompileShaderBlob calls D3DCompile on embedded source directly, not the file/disk shader cache. Mode/strength are parsed from the effective config/env and frozen at helper creation. These source facts do not establish actual game activation; successful initialization and processed frames remain necessary.
