# Isolated complete NR native D3D12 prototype

This restores and exercises our own existing `NativeActualNetwork70` full71 HLSL implementation, using the actual SM6.10 wave-matrix/FP8 shader family. It does not copy or execute Daniel's closed binary. No game backend selector, player DLL/configuration, release package or installation is changed. Default production remains HIP.

Build with `build.sh` (MinGW C++17/O2). Reuse the existing private Agility721 files and existing DXC1.10.2605.24; no SDK installation. Matrix capability was actually verified on RX9070XT: hardware highest shader model6a, FP8 E4M3FN/F16 Wave32 PSOs and5 dyadic/asymmetric primitive cases passed4 K32/twoK16/partial/late-C variants. Standalone experimental-device support does not prove an already-created game device supports this path.

`stage-assets.ps1` copies legacy assets into an isolated directory and adds the existing original noise file; disk shader-cache writes are disabled. `full71.flags` is the previously validated fast43 wave/FP8 recipe with skip/debug/output smoothing/residency extras removed. `run.ps1 -Phase gold` runs two real full-network evaluations; `-Phase pilot` uses10 warm +20 measured samples and first/last reads outside timing. Flags are mandatory, inherited DLSS5 variables are cleared, input size/finite data and1920x1152/valid1080/640-token geometry are checked. No temporal history, MP1, style1, seed0, no AE reuse. The RGBA32f input is the locked controlled encoded gradient1152 reflection, SHAb3d114c4..., not a gameplay capture.

The native caller intentionally uses the legacy protected **chunked Run**. It does not enable `TEST_SINGLE_LIST` or bypass the whole-list DEVICE_HUNG guard. Outer GPU timestamps include all chunk submissions and CPU/fence idle gaps; host intervals additionally include the two outer timestamp submissions and map. These are inclusive standalone legacy measurements, not kernel-duration sums. `hip1152.ps1` measures the existing validated HIP implementation afresh at the same shape/input; math/noise and exact timed segments still differ, so their time ratio is not API causation.

Source repair: prefix `raw_features=false` makes `wave_ffn_local=false`; the old raw-store test therefore selected a descriptor root lacking t3, although the actual FAST3 shader required t0..3/u0/b0. Including `prefix_wave` in that selector creates/uses the already-matching raw root. The actual current inline-prefix bindings and two full-network executions passed. It changes root binding selection, not shader arithmetic. The added getter exports actual Vit31 input only for diagnostics. `NR_DX12_PSO_DIR` captures created PSO bytecode at initialization only and is off by default; created PSOs include unused variants and are not dispatch counts.

Evidence and limitations: `Development/results/nr-native-dx12-pure-20261009`. Full71 finite/nonzero/repeat-bit0 passed; relative to same1152 HIP reference PSNR51.38dB, not bit-exact. Stored legacy noiseAA38f7.../50,331,648 float values versus HIP's procedural noise path is not proved equivalent. Legacy HLSL retains older stage decomposition, normalization/rounding and intermediate traffic; current HIP wave-owned/persistent fused operators have **not** been newly ported into this backend. Compact1088 tail-masked downsample/head is not implemented; its extent guard is preserved. The safe native4-stage batch separately passes output-bit0 but its single timing pair did not improve host wall time. No positive performance or game-device deployment conclusion follows.
