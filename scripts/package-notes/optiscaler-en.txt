OptiScaler-DLSS5-AMD @VERSION@ — standard full game package

0.32
1. Switching resolution or DLSS preset no longer leaks VRAM: the AMD HIP driver never returns imported shared buffers, so each switch used to lose 70-90 MB (several GB after dozens of switches); buffers are now reused per network tier, capped around 200 MB.
2. C32 input reads as whole-line vector loads (bit-identical, about -0.9%).
0.31 -> 0.32 kernel output is bit-identical.

1. Tier choice: an input at most 10% beyond a tier on both axes is fitted DOWN into it instead of UP into the next. 2K quality (1707x961) used to be upscaled into the 1080 tier (35% more interpolated pixels); it now takes a 6% downscale into 900. Stellar Blade 2K quality main menu about 47 -> 57 fps.
2. One-head-per-wave kernels: C32/C64/C128 blocks and C256 attention keep a whole head's window in one wave's registers (DLSS5_HIP_WAVE_OWNED=1). Bit-identical, about -6% whole network.
3. C512 QKV/mix at 32 tokens per wave (DLSS5_HIP_C512_M32=1, about -1.3%); ViT projection 64 columns per wave (DLSS5_HIP_VIT_PROJ_N64=1, about -1.8% at 1080). Bit-identical.
Set any of the three flags to 0 to return to the 0.30 path. 0.30 -> 0.31 kernel output is bit-identical (the tier rule changes the fit, not the network arithmetic).
4. Adaptive ViT reuse on by default (DLSS5_VIT_ADAPTIVE=1): while the picture is still, ViT results are reused across frames (+3 fps on Stellar Blade's static main menu); any motion falls back to full computation at no extra cost. F8 toggles reuse/full. Lossy; set 0 to disable.
Measured (RX 9070 XT, over Splashtop, Stellar Blade main menu): 2K quality 57 fps (simple scene hits a 60 cap), 2K Native AA 43-44.
The regular OptiScaler framework retains the 0.27 baseline; this is not the RE9 host.

Exit the game, back up existing mod files, and extract ALL files beside the actual game executable (often Binaries/Win64). Select DLSS input in the game; OptiScaler routes it to FSR. Supported integration is low-resolution rendering → DLSS5 → FSR → display. Neural input is no longer size-limited: tiers are 720/900/1080 and an input at most 10% beyond a tier is fitted down into it; above 1080p it is fitted onto the 1080 tier and restored (DLSS5_FIT_LARGE=1). F6 toggles NR; Insert opens OptiScaler; Home opens ReShade.

DLSS5-AMD/native-game-flags.txt uses the repository standard template and NETWORK_HEIGHT=auto. Existing block skips remain; adaptive reuse is on (F8 switches reuse/full; set DLSS5_VIT_ADAPTIVE=0 to disable). DLSS5_SHOW_FPS and DLSS5_NOTICE control the corresponding information.

Use this route for existing supported games such as Stellar Blade, Lies of P and Cyberpunk 2077 (2.31, no configuration). RE9 uses the separate REFramework package; do not mix the two hosts/runtimes. Avoid simultaneously processing the same game through Magpie.

Full model and gfx1200/gfx1201 modules included. Requires AMD driver HIP7 (amdhip64_7.dll); RX9070XT tested, gfx1200 hardware feedback still needed. Verify files with SHA256SUMS.txt. Framework and third-party licenses remain included.
