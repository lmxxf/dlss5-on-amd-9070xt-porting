Magpie-DLSS5-AMD @VERSION@ — 完整便携包

0.45 保持 0.44 的 Small 0.5x 默认、F9 热修和 MODE/AE 策略。F9 仍按 0.5→1→2→3→0.5 切换；缺少 Small 权重仍回退 Original 1x。安装前完全退出游戏，保留个人 custom-config.txt/native-game-flags.txt。

本版补齐紧凑字节路径、采用 V 片段布局与 C512 成对 FP8。Q/K 片段布局仅默认用于 Original900（1600×960）和 Small900/1080（1600×1024、1920×1152），其他形状保留 V-only。DLSS5_HIP_VIT_QKFRAG=0 关闭；设为1也不扩大范围。负性能候选不随包启用。

附带每架构40个HIP模块（合计80）；gfx1201已做GPU验证，gfx1200仅编译与目标/校验和核验。源码附件对应发行宿主、内核与配置，不需要重新编译已附二进制。下方旧版性能数字属于历史记录，不是0.45的新游戏帧率承诺。

以下是历史0.40说明，FPS/耗时不是本次整包性能承诺。
更新（0.40）
1. 默认输出变了：全 71 块 + 快速数值（DLSS5_SKIP_BLOCKS= 留空，DLSS5_FAST_NUMERIC=1）。对 NVIDIA 原版 44.26 → 47.55 dB，偏色消失；每帧比 0.39 慢约 0.12/0.19ms（900/1080）。想要 0.39 的输出：custom-config.txt 里写 DLSS5_SKIP_BLOCKS=42,43,46 和 DLSS5_FAST_NUMERIC=0。
2. 叠层 DLSS5_MULTI_PASS=1/2/3（默认 1）：网络把自己的输出再跑 1～2 遍，风格更浓，耗时约 N 倍。游戏里按 F9 在 1→2→3 之间轮换，下一帧生效，选择写进 custom-config.txt（native-game-flags.txt 里也写了这一项的话一并改；设了同名系统环境变量则按键无效）。改键：DLSS5_MULTI_PASS_HOTKEY（F1～F24 或键码，0 关闭）。《剑星》2K 实测 1/2/3 遍 57/37/27 fps，3 遍可以配帧生成玩。
3. 三层配置文件，见下面“配置文件”。行为变化：系统环境变量现在压过文件（以前是文件压过环境变量）。
4. 逐位提速：C32/C64 窗口核改 LLVM 23 编、1080 档专用 C32 等，离线每帧 900 约 −0.1ms、1080 约 −0.2ms。

配置文件（0.40 起三层，同一项后面的覆盖前面的）
1. DLSS5-AMD/default-config.txt：包里的默认配置（来自仓库模板），每次升级会被覆盖，不要改它。
2. DLSS5-AMD/custom-config.txt：你自己的设置。包里不带这个文件，第一次用时把 custom-config.template.txt 复制一份改名为 custom-config.txt，只写想改的那几行（例如 DLSS5_MULTI_PASS=2）。安装和升级都不会碰它。
3. DLSS5-AMD/native-game-flags.txt：旧版的单文件。老用户已有的照常生效，而且优先于 custom-config.txt；包里也不再带它，所以解压覆盖升级不会冲掉。
系统环境变量里的 DLSS5_* 比三个文件都优先。同一文件里同一项写两次以最后一行为准；值留空（KEY=）表示用程序内置默认。

有损项（都是可选的，写进 custom-config.txt）
- 默认就开着的：DLSS5_FAST_NUMERIC=1（快速数值，对逐位输出最差帧约 51.8 dB，对 NVIDIA 基本不变；写 0 = 逐位，每帧慢 0.07～0.13ms）。
- DLSS5_SKIP_BLOCKS=42,43,46：跳三块，每帧快 0.20/0.32ms（900/1080），对 NVIDIA 约掉 3.3 dB，有整体偏色。和 DLSS5_FAST_NUMERIC=0 一起写就是 0.39 的输出。
- DLSS5_NETWORK_1080_ROWS=1088：1080 档快约 0.45ms，对 1152 行约 54～56 dB。
- DLSS5_NETWORK_HEIGHT=900：本该走 1080 档的输入也压到 900 档，快约 2.7ms，画质代价未量化。
- DLSS5_MULTI_PASS_SKIP_BLOCKS：只在叠层第 2 遍起跳块。省得少，跳多了会变成另一种风格，不推荐。

更新（0.39）
默认设置下与 0.38 逐位相同（输出一个比特不差），只是更快：一批逐位重排的新核（C512 FFN 在寄存器里一个 wave 做完、ViT QKV/attention、C32/C64 读权重外提、解码加宽等）。离线网络：900 档约 7.27 → 6.8ms，1080 档约 10.05 → 9.5ms；《剑星》2K 实测约 +1.5～2 帧。
新开关：DLSS5_STYLE=1（NVIDIA NGX 的 Style 控制，0/1/2）。1 = 原版在《剑星》里用的风格，也是以前各版写死的值（默认，逐位不变）；0 = NVIDIA 默认、最接近其参考图；2 = 第三种风格。改了要重启游戏。
add-on 可复现构建：同一份源码在哪编都得到同一个文件。

更新（0.38）
默认设置下与 0.37 逐位相同（输出一个比特不差），只是更快：
1. 900 档：去掉 C512 的 shift_pack 派发（按 16 token 补齐分配，容量不够自动回退）。
2. C32：块 4 跳连/下采样、prefix 下采样、块 69 主干改存 E4M3 字节；对角残差跳过全零半块；prefix/finish 字节尾一次写 8 字节。
3. 量化精简（2³² 穷举证明）：C64/C256 与 C512 出口 FP8 舍入改位掩码；C512 QKV-attention 去掉多余钳位、改有界倒数；C256 FFN 按 16 字节片段读权重；C512 字节副本经 LDS 转置宽写；C512 mix、ViT contract 占用上限。
每帧派发：900 档 179 → 162，1080 档 162 → 158。离线网络（整帧回放）：900 档约 8.0 → 7.6ms，1080 档约 10.8 → 10.4ms。
新开关：DLSS5_FORMAT_FALLBACK=1（原表以外的颜色格式，如 R10G10B10A2、B8G8R8X8、R9G9B9E5、R32G32B32(A32)，在 pre-upscale 路线上转成 RGBA16F 再处理；原来支持的格式不变；设 0 关闭）。DLSS5_HOT_RELOAD=1（游戏运行中改本文件的 DLSS5_STRENGTH / DLSS5_NOTICE / DLSS5_SHOW_FPS，一秒内生效、不用重启；其他键仍需重启）。
可选、有损、默认不开：DLSS5_NETWORK_1080_ROWS=1088 让 1080 档只算 1088 行（NVIDIA 原版 1152 行），约快 0.47ms，但整帧输出都会变（对 1152 约 56dB）。要 NVIDIA 原版几何就保持 1152。

更新（0.37）
每一步都与 0.36 逐位相同（输出一个比特不差），只是更快：
1. C512 点运算紧凑布局：FFN/卷积只算有效 tile，补边推迟到 attention 读取时（两档各约 −2%）。
2. C512 head 池化与投影合成一次派发；ViT attention 分数排布转置。
3. C256 持久化（新开关 DLSS5_HIP_SWIN_RUN=1，本模板默认开）：C256 编码/解码各六个内部层走设备就绪队列；约 100ms 超时即在 GPU 上重算该段并在本会话停用。设 0 回到原派发。
4. ViT attention 新核（640 token 约 71 → 38µs）；ViT QKV 五个 wave 经 LDS 共用权重（约 49 → 37µs）。
每帧派发：900 档 198 → 179，1080 档 182 → 162。离线网络 900 档约 8.5 → 8.0ms。《剑星》2560×1440 原生 AA、EXACT：54 → 55～56。

更新（0.36）
1. 算术精简（每一步都与上一版逐位相同）：C32 激活去掉多余的 NaN 规范化；C64～C256 的 softmax 改用有界倒数（求和顺序与舍入修正不变）。
2. float FMA 激活（C32、C64～C256、ViT/C512）：乘加合成一条 float FMA，只舍入一次（NVIDIA 原版在这里用的是 half FMA，同样一次舍入）。输出因此有细微变化：0.36 与 0.35 不逐位相同（对 NVIDIA 原版的误差基本持平），0.36 起为新的逐位基准。
3. 块融合：C256 整块核并在 token 组间共用 FFN 权重（1080 档）；C512 的 QKV 与 attention 融合；C64/C128 FFN 权重复用；C32/C64/C128 上采样融进首块。1080 档每帧派发 214 → 182。
4. 输入直写（DLSS5_DIRECT_IO=1，默认开）：输入 pass 直接写进 HIP 共享缓冲，省一次 35MB 拷贝。取 3 时前置超分模式下还把解码输出直接交给 FSR（非默认）；0 为原路径。
5. 帧时间日志 DLSS5_FRAME_STATS=<秒>（默认 0）：每个窗口写一行到 DLSS5-AMD\logs\frame-stats.txt。
离线网络相对 0.35：900 档约 −0.79ms（−8.5%），1080 档约 −1.13ms（−8.9%）。《剑星》1080P 原生 AA、EXACT：约 57 → 59～60（已触窗口模式 60Hz 上限）；2560×1440 原生 AA、EXACT：54（新的对比标尺）。

更新（0.35）
1. C32 三轮逐位提速：去掉重复的 FP8 往返、RTZ 与 LDS 读写向量化、打包段按段开关饱和模式、prefix/finish 完整窗口免逐像素裁切。
2. ViT 字节流（DLSS5_HIP_VIT_STREAM=3，新增 vit-stream 模块）：注意力 AV 结果直接以字节写入投影，contract 段走 half 接口；与自适应复用兼容。1080 档约 −1.3%。
离线网络 900 档约 9.3ms、1080 档约 12.75ms（0.34 为 9.6 / 13.4）。《剑星》1080P 原生 AA、EXACT 普通场景 54 → 56.7 左右。
0.34→0.35核输出逐位相同。

0.34 更新
1. 继续压普通算术指令（逐位相同）：FP8转换前的clamp改用单条med3/fmed3、去掉编译器插入的规范化；C64～C256打包段按段开关饱和模式、乘积与−0→+0合成一条fma。离线网络900档9.80→约9.6ms、1080档13.64→约13.4ms。《剑星》1080P原生AA、EXACT：主菜单50～51、常见场景54。
2. PDL旗子计数长时间运行可能回绕、提前放行，已修；退出时释放PDL缓冲。
0.33→0.34核输出逐位相同。

0.33 更新
1. FP8打包提速：C32与C64～C256核把两个值用一条转换指令直接写进矩阵片段，省掉逐字节拼装（逐位相同）。离线整网900档10.74→9.80ms、1080档15.01→13.64ms（约−9%）；《剑星》1080P原生AA、EXACT：主菜单47～48→49～50，常见场景51～52→53～54。
2. 黄字末尾显示AE/EXACT（F8切换时可见；以前只挂在被隐藏的FPS行）；F7隐藏/显示屏幕文字。
0.32→0.33核输出逐位相同。

0.32 更新
1. 切分辨率/DLSS档位不再漏显存：AMD HIP驱动不归还导入过的共享缓冲区，以前每切一次漏70～90MB（切几十次就是几GB），现在按网络档位复用，封顶约200MB。
2. C32输入改整行宽读（逐位相同，约−0.9%）。
0.31→0.32核输出逐位相同。

0.31 更新
1. 档位选择：输入只比某档大一点（两轴都不超过10%）时，往下缩进该档，不再放大到下一档。2K质量档（1707×961）以前放大进1080档（多算35%插值像素），现在缩6%进900档。《剑星》2K质量档主菜单约47→57fps。
2. 一头一wave核：C32/C64/C128整块与C256注意力，一个wave负责一个头的完整窗口，中间结果留在寄存器（DLSS5_HIP_WAVE_OWNED=1）。逐位相同，整网约−6%。
3. C512 QKV/mix每wave 32 token（DLSS5_HIP_C512_M32=1，约−1.3%）；ViT投影每wave 64列（DLSS5_HIP_VIT_PROJ_N64=1，1080档约−1.8%）。均逐位相同。
以上三个开关设0即回到0.30对应路径。0.30→0.31核输出逐位相同（档位选择改变的是缩放方式，不是网络算术）。
Magpie宿主与原流水线沿用0.27底包。

使用
1. 完整解压到独立目录，运行Magpie.exe。不要只复制addon，也不要覆盖正在运行的版本。
2. 游戏设为窗口。按720/900/1080档处理，只比某档大10%以内的往下缩进该档；超过1920×1080缩到1080档再还原（DLSS5_FIT_LARGE=1）。900P是可选的性能折中。
3. 选择包内DLSS5效果组：FSR3_SR（DLSS5入口，保持输入尺寸1倍）→ FSR4放大 → XeSS帧生成。
4. Alt+Shift+A启动/停止缩放；F6开关神经处理；F7隐藏/显示屏幕文字。
5. AMD光流只在第一项使用；FSR4/XeSS后续项选None，避免额外光流导致发糊。

配置
DLSS5-AMD/default-config.txt来自仓库hip-magpie-flags.txt。NETWORK_HEIGHT=auto按输入选择720/900/1080。默认全71块+快速数值，自适应复用默认关闭；F8仅在显式开启复用热键后生效。
显示由DLSS5_SHOW_FPS、DLSS5_NOTICE控制；两项均设0可关闭对应显示。配置键保留完整DLSS5_前缀。

内容与环境
本包包含模型、配套DLL/shader和gfx1200/gfx1201各34个HIP模块，不是补丁。需要AMD驱动提供amdhip64_7.dll；HIP路线不依赖SM6.10预览组件。9070 XT已实测，9060系列仍需要对应硬件反馈。
