0.40 更新
1. 与常规包同一套核和默认配置：全 71 块 + 快速数值（对 NVIDIA 44.26 → 47.55 dB，每帧慢约 0.12/0.19ms）；想要 0.39 的输出，custom-config.txt 里写 DLSS5_SKIP_BLOCKS=42,43,46 和 DLSS5_FAST_NUMERIC=0。
2. 叠层 DLSS5_MULTI_PASS=1/2/3（默认 1，风格更浓，耗时约 N 倍）。RE9 runtime 没有热键，改配置后重启游戏。
3. runtime 读三层配置文件（见下面“配置文件”），并新增从文件读 DLSS5_STYLE、DLSS5_FRAME_STATS、DLSS5_FAST_NUMERIC、DLSS5_MULTI_PASS、DLSS5_MULTI_PASS_SKIP_BLOCKS、DLSS5_NETWORK_FREE_RES（0.39 写在模板里的 DLSS5_STYLE 现在生效）。行为变化：同一文件里同一项写两次，现在取最后一行（以前取第一行）。
4. 输入直写，少一次 35MB 拷贝；给集成方的 GetTimings。宿主 dxgi.dll 不变。

配置文件（0.40 起三层，同一项后面的覆盖前面的）
1. DLSS5-AMD/default-config.txt：包里的默认配置（来自仓库模板），每次升级会被覆盖，不要改它。
2. DLSS5-AMD/custom-config.txt：你自己的设置。包里不带这个文件，第一次用时把 custom-config.template.txt 复制一份改名为 custom-config.txt，只写想改的那几行（例如 DLSS5_MULTI_PASS=2）。安装和升级都不会碰它。
3. DLSS5-AMD/native-game-flags.txt：旧版的单文件。老用户已有的照常生效，而且优先于 custom-config.txt；包里也不再带它，所以解压覆盖升级不会冲掉。
系统环境变量里的 DLSS5_* 比三个文件都优先。同一文件里同一项写两次以最后一行为准；值留空（KEY=）表示用程序内置默认。

有损项（都是可选的，写进 custom-config.txt）
- 默认就开着的：DLSS5_FAST_NUMERIC=1（快速数值，对逐位输出最差帧约 51.8 dB，对 NVIDIA 基本不变；写 0 = 逐位，每帧慢 0.07～0.13ms）。
- DLSS5_SKIP_BLOCKS=42,43,46：跳三块，每帧快 0.20/0.32ms（900/1080），对 NVIDIA 约掉 3.3 dB，有整体偏色。和 DLSS5_FAST_NUMERIC=0 一起写就是 0.39 的输出。
- DLSS5_NETWORK_1080_ROWS=1088：1080 档快约 0.45ms，对 1152 行约 54～56 dB。
- DLSS5_NETWORK_HEIGHT=900：本该走 1080 档的输入也压到 900 档，快约 2.7ms，画质代价未量化。
- DLSS5_MULTI_PASS_SKIP_BLOCKS：只在叠层第 2 遍起跳块。省得少，跳多了会变成另一种风格，不推荐。

这是专门针对《生化危机9 / Resident Evil Requiem》特殊命令提交方式的版本，不是通用OptiScaler版。宿主基于TheAutomatic的release/1.9.0，并接入本项目HIP runtime。感谢TheAutomatic的前置设计和PR贡献。

本版变化
旧0.27为FSR之后的后处理、固定900P、最高1080P SDR输出。本版改为：游戏低分辨率渲染→HIP DLSS5→FSR超分→最终显示，已验证2K无边框输出。神经输入仍要求宽≤1920、高≤1080，网络按输入自动选择720/900/1080。
接通同帧游戏曝光：编码时归一化，解码后还原场景亮度，修复原先曝光遗漏导致的大面积泛白/褪色；Detail/Colour strength均默认1。加入录制前HIP权重/核准备。共享核包含常规版六项无损优化。

安装
1. 完全退出游戏。备份已有MOD文件，将本包完整解压到re9.exe旁。
2. 升级旧版必须移走根目录和_storage_里的旧dlss5-amd.addon64、re9-present.addon64及旧观察器addon，防止重复处理。
3. 如果_storage_中已有dxgi.dll或LmxxfNrRuntime.dll，用本包同名文件同步替换；有该目录的OptiScaler.ini也应同步。dxgi.dll和LmxxfNrRuntime.dll必须配套，不要与普通版混装。
4. 本包保留REFramework dinput8.dll。已经有其他dinput8模组时先处理冲突。
5. 游戏选择DLSS超分，建议先2K输出、平衡档、关闭帧生成测试。确认画面稳定后再按需测试帧生成。本包不附个人游戏设置或存档。

控制与配置
F6开关神经处理；Insert打开OptiScaler/REFramework菜单（两者默认键可能重叠）。Detail strength、Colour strength可在神经渲染菜单调节；保持0～1。调低颜色强度也会削弱彩色纹理/材质效果，不只是改变饱和度。
配置在OptiScaler.ini的[DlssNr]，默认NrBackend=lmxxf、Enabled=true、RunBeforeSR=true、LmxxfDiagnostic=off。显示由OptiScaler菜单管理；旧addon的F7和DLSS5_SHOW_FPS/NOTICE不控制此版。
此runtime从DLSS5-AMD下的三层配置文件读取DLSS5_HIP_*、DLSS5_SKIP_BLOCKS、DLSS5_FIT_LARGE、DLSS5_NETWORK_HEIGHT及0.40更新里列出的键，其余键不生效；不提供普通addon的F8/F9热键；默认全71块+快速数值、关闭跨帧自适应复用。不要用旧0.27配置说明调整新runtime。

验证范围
9070 XT数值回归、曝光倍率对照、主菜单连续运行和重启验证通过；完整游戏画质、切场景和帧生成仍需进一步实玩反馈。旧0.27曾在Xbox《鬼武者》验证，但不能据此认为本版新前置宿主也已验证该游戏。其他RE游戏/9060硬件未实测；HDR显示输出未完成验证。
