# DLSS5 显示合成开关对照

2026-09-05，RX9070XT，1920×1080，修复抗锯齿OFF后的干净前端四层版本。

每组以固定相机连续拍摄：on=mode0神经残差合成，off=mode1原生FSR画面，split=mode2左原生/右神经，restored=返回mode0。脚本检查模式切换日志，两个场景均通过，最后恢复开启。

这里的“关闭”只绕过显示合成，网络依然计算，不是卸载DLL后的性能对照。人物待机、无人机、粒子、时序抖动仍随时间变化，on/off并非同一输入帧；不要把这些动画差异归于神经效果。split在同一帧中展示两个模式，但左右内容也不是同一像素。

初步肉眼观察：这两个场景尚看不出稳定、显著的画质提升，不能仅凭完整网络已执行就宣称效果正确或值得其耗时。此次只完成原始截图采集，未放大残差、调色或修饰截图。
